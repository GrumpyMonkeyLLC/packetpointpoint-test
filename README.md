# Buckeye Threads Website - Modernized

## Website Structure

This is a complete modernized website for Buckeye Threads, Inc. with all pages organized in subdirectories.

### Main Directory Structure
```
buckeyethreads/
├── css/
│   └── styles.css          (Shared stylesheet for all pages)
├── index.html              (Homepage)
├── distinctives.html       (Company distinctives)
├── quality.html            (Quality assurance info)
├── products.html           (Complete product catalog)
├── brands.html             (Brands and materials)
├── catalog.html            (Catalog request page)
├── surplus.html            (Surplus inventory)
├── history.html            (Company history)
├── mission.html            (Mission statement)
├── terms.html              (Terms & conditions)
├── employment.html         (Job opportunities)
└── contactus.html          (Contact information)
```

### Key Updates from Original Site

1. **Updated Years**: Changed from 32 to 42 years of service (1984-2026)
2. **Modern Design**: Clean, professional industrial aesthetic
3. **Complete Product Details**: All 8 product categories with specifications
4. **Responsive Layout**: Works on all devices
5. **Organized Structure**: CSS in separate file, all pages in root directory
6. **Enhanced Content**: Added detailed information for all sections

### Design Features

- **Color Scheme**: Charcoal, steel, and orange accent colors
- **Typography**: Work Sans and DM Mono fonts for modern, professional look
- **Animations**: Subtle fade-in effects and hover states
- **Navigation**: Sticky navigation bar with active page highlighting
- **Layout**: Responsive grid system that adapts to all screen sizes

### To Deploy

1. Upload entire `buckeyethreads` folder to your web server
2. Ensure the `css` subdirectory maintains its structure
3. Set `index.html` as your default page
4. All internal links are relative and will work correctly
